# Mongol Target Shooting — React Website

A responsive React/Vite landing page based on the uploaded hunting / target-shooting brochure.

## Run locally

```bash
npm install
npm run dev
```

Then open the localhost URL shown by Vite.

## Build for production

```bash
npm run build
```

The deployable output will be created in the `dist` folder.

## Easy edits

- Main text/content: `src/App.jsx`
- Design/colors/layout: `src/styles.css`
- Brochure images: `src/assets/`
- Phone number: search `+976 9811 3270` in `src/App.jsx`

## Deploy

This project works well on Netlify or Vercel.
For Netlify:
- Build command: `npm run build`
- Publish directory: `dist`
